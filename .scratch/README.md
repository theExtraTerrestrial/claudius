# .scratch

Working notes and an issue log, kept in the repo because the reasoning behind a
deferral is worth more than the deferral itself — and because a note that lives
in someone's head or a chat window is a note that is already lost.

Not part of the product. Nothing here is installed, executed, or read by
`claudius` at runtime.

```
.scratch/
  front_end/    the dashboard page and its sidecar
```

One file per issue, numbered per area (`001-…`, `002-…`), with a status line at
the top. Close one by marking it **closed** and saying what happened, or delete
it if it turned out not to be real. Write down *why* something was deferred, not
just that it was — the next person to look is usually you, months later, about to
re-derive the same conclusion.
